Industrial-Failure-Predictor
This project uses the "AI4I 2020 Predictive Maintenance Dataset" to build machine learning models that predict machine failures and explain why those failures are likely to occur. The goal is to support proactive maintenance, reduce unplanned downtime, and provide transparent, explainable insights to engineers.
Key insights - Features like torque, tool wear, and rotational speed strongly influence failure risk. - SHAP plots reveal how combinations of high torque and high tool wear increase failure probability. - LIME explanations make single predictions interpretable for engineers, supporting trust and adoption.
Tech stack - Python,Pandas, NumPy, Scikit-learn, XGBoost, SHAP, LIME, Matplotlib, Seaborn, Google Colab
